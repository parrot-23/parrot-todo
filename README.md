# Parrot Todo

Parrot Todo is a weekly schedule planner for Obsidian. It combines time blocks, event planning, and execution tracking so you can plan a week, place tasks on specific days and hours, and then review how the plan actually went.

## Features

- **Tasks**: register tasks with main and branch lines, nested subtasks, checklists, stage goals, files, and check-ins.
- **Plans**: lay tasks out on a yearly week axis, plan each week with day cards and daily goals, and color hours in the time box view.
- **Check**: compare planned and actual time per category, review today's share, and summarize weekly notes and daily goals.
- **Today card**: track completion and accumulate execution time; habits appear near their time and can be completed or skipped.
- **Inbox**: capture ideas at any time and turn them into real tasks later.
- **Themes**: switch between built-in visual themes and customize the interface layout with cards.
- **Data sovereignty**: all records are stored locally in your vault, and data can be exported to Excel/CSV for backup, analysis, or migration.

## Usage

1. Enable the plugin in **Settings → Community plugins**.
2. Click the calendar icon in the ribbon, or run the **Open week schedule panel** command from the command palette.
3. Use the top toolbar to reach functions, inbox, calendar, settings, and help.
4. Click **Layout** to enter edit mode, where you can add cards, switch themes, and adjust the interface.
5. Open the help panel from the top toolbar for a guided overview of tasks, plans, check, and data.

## Settings

Open **Settings → Parrot Plan Settings** to configure script mode and manage plugin data.
